# whisper_discord_botv2

ALL RIGHTS RESERVED


a discord bot that sends anonymus messages, this bot has 4 main functions 

1. /whisper                        the basic function, it sends an anonymus message in the respective channel
2. /edit                           it edits the anonymus message
3. /delete                         it deletes the specified anonymus message
4. /whisper-reply                  it can anonimusly reply to a anonymus or normal message
